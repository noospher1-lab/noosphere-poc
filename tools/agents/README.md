# Агенты: пять ИИ-участников, которые пользуются PoC

Стенд, чтобы увидеть платформу в работе, когда живых тестеров ещё нет: пять
агентов заходят в Ноосферу как обычные участники и проходят полный круг —
читают проблему, спорят, получают PoI, сводятся в позиции, голосуют.

Агент ходит через тот же HTTP API, что и браузер. Прямая запись в базу ровно
одна — отметка «почта подтверждена»: иначе на выдуманные адреса полетели бы
настоящие письма.

## Запуск

```bash
./serve.sh                     # стенд на :8000 — грант $3, без инвайтов, без писем
python3 runner.py --problems problems.json --rounds 2
```

Продолжить в уже заведённых проблемах, проголосовать по одной из них:

```bash
python3 runner.py --topic 33 --topic 34 --rounds 2 --vote-on 33
```

Полезные ключи: `--agents N`, `--budget 3`, `--model`, `--effort`,
`--no-vote`, `--vote-turns`, `--seed` (воспроизводимый порядок ходов).

## Лимит на ИИ

У агента ОДИН лимит, по умолчанию $3 — как грант живого тестера. В него входят
обе стороны расхода:

- **своё** — размышления агента в этом раннере (выбор хода, письмо довода,
  реплики в диалоге голосования);
- **платформа** — то, что он тратит внутри PoC: компаньон черновика, оценка
  PoI, собеседник и судья голосования. Эту часть считает сам PoC в
  `usage_events`, раннер читает её через `/api/me/profile`.

Кончились деньги — агент замолкает и остаётся в графе с тем, что успел сказать.
Лимит настоящий, а не декоративный: `serve.sh` сознательно НЕ включает
`DEV_TOOLS` — под ним `spend_llm()` пропускает проверку гранта.

## Почему агенты не служебные аккаунты

`is_service` отключает ИИ целиком и снимает оценку с публикаций (vault:
`decisions/service-account.md`). Прогон затевается ровно ради того, чтобы
увидеть компаньона и PoI в работе, поэтому агенты — обычные аккаунты. Из этого
следует и обратное: **их тексты нельзя лить в боевой граф** — там они встанут
в общий рейтинг рядом с человеческими, а это ровно то, что решение о служебном
аккаунте запрещает. Стенд локальный по умолчанию и таким должен остаться.

## Файлы

| файл | что делает |
|---|---|
| `serve.sh` | поднимает PoC с окружением прогона |
| `runner.py` | сценарий: вход, постановка проблем, раунды, позиции, голосование, итоги |
| `personas.py` | пять складов мышления (не пять мнений) |
| `brain.py` | вызовы модели и общий кошелёк агента |
| `poc.py` | клиент к API — те же вызовы, что делает браузер |
| `view.py` | что агент видит, открыв проблему |
| `problems.json` | постановки проблем для посева |
